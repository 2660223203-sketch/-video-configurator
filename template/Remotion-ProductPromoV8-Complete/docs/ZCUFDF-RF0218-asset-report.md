## 缺失素材影响

- **产品图片缺失**：组件会渲染占位符，不影响项目编译和结构验证
- **操作视频缺失**：背景使用科技渐变 + 网格代替，工业感稍弱
- **音乐缺失**：无音乐版本可正常渲染
- **二维码缺失**：片尾仅显示文字联系方式

## 拿到素材后的替换步骤

1. 将素材放入 `public/assets/` 对应子目录
2. 修改 `src/config/assets.ts` 中对应路径
3. 在 `src/config/content.ts` 中确认产品参数与正式文件一致
4. 运行 `npm run preview` 预览效果
5. 微调各场景的 `startFrom` 等参数
6. 运行 `npm run build` 渲染最终视频
